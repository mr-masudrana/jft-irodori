# Irodori JFT-Basic App (v5.3)

PWA: Irodori লেসন + SRS রিভিউ + শব্দ কুইজ + JFT-Basic মক টেস্ট।

## চালানো
```
npm install
npm run dev
npm run build
```

## v5.3 — UI/UX রিফাইনমেন্ট
- নতুন ডিজাইন টোকেন (রেডিয়াস স্কেল, গভীর শ্যাডো, ব্র্যান্ড গ্রেডিয়েন্ট); কার্ড/বাটন/অপশনে নরম ফোকাস-রিং ও স্পর্শ-ফিডব্যাক
- হিরোতে নরম আলোর আভা ও কাচের মতো স্ট্যাট টাইল; হেডার আরও ঝাপসা-কাচ
- নিচের ট্যাব বার: বড় পিল, অ্যাক্টিভ ট্যাবে ডট-সূচক

## v5.2 — বাগ ফিক্স
- **package.json** নতুন করে যোগ (আগেরটি খালি ছিল); Tailwind v3.4.17, Vite 5, React 18
- **মক টেস্ট:** প্রশ্ন ৮ → ২০টি; উত্তরের অবস্থান এলোমেলো (আগে সবই ১ নম্বর অপশন ছিল); টাইমার এখন শেষ-সময়ের timestamp থেকে হিসাব হয় (ফোন লক/ব্যাকগ্রাউন্ডে ঠিক থাকে); চলমান পরীক্ষা অন্য ট্যাবে গেলে বা রিফ্রেশে হারায় না; ফলাফল/XP ডুপ্লিকেট হওয়া বন্ধ; XP দিনে একবার
- **অডিও:** ২x মোডে থামালে/অন্য অডিও চালালে/পেজ ছাড়লে দ্বিতীয়বার আবার বাজার বাগ ঠিক; TTS না চললে বাটন আটকে থাকত — এখন বার্তা দেখায়; মোর পেজে জাপানিজ voice আছে কি না দেখায়
- **ডার্ক মোড:** `tailwind.config.js`-এ `darkMode: ['selector', '[data-theme="dark"]']` — `dark:` ক্লাস এখন অ্যাপের টগল মানে
- **SRS:** কার্ড id এখন শব্দ-ভিত্তিক স্থায়ী id (ভোকাবুলারি যোগ/বাদ/ক্রম বদলালেও অগ্রগতি ঠিক); পুরনো ডেটা প্রথম খোলায় স্বয়ংক্রিয় মাইগ্রেট হয়। শব্দে চাইলে নিজস্ব `id` ফিল্ড দিতে পারেন
- **XP ফার্মিং রোধ:** রিভিউয়ে শুধু due কার্ডে XP; কুইজ XP প্রতি লেসনে দিনে একবার
- **PWA:** PNG আইকন (192/512/maskable) ও `apple-touch-icon.png` যোগ; সার্ভিস ওয়ার্কার শুধু প্রোডাকশনে (dev-এ পুরনো SW/ক্যাশ মুছে ফেলা হয়); ফন্টের CSS অফলাইনে ক্যাশ হয় (`crossorigin`)
- অন্যান্য: `localStorage` try/catch, Fisher–Yates shuffle, রিভিউ কার্ডে কিবোর্ড ইভেন্ট ফিক্স, কুইজের টাইমআউট ক্লিনআপ

## কনটেন্ট যোগ
ডেটার গঠন: `src/data/books/<বই>/book.json` (বইয়ের তথ্য) + `src/data/books/<বই>/lesson_01.json`, `lesson_02.json` ... নতুন ফাইল যোগ করলে নিজে থেকেই লোড হয় (index.js বদলাতে হয় না)।
URL hash দিয়ে নেভিগেশন চলে: রিফ্রেশে একই পেজে থাকে, ফোনের ব্যাক বাটন ধাপে ধাপে পেছনে যায়।
নেভিগেশন: বই → লেসন (টপিকসহ) → লেসনের অ্যাক্টিভিটি/বিস্তারিত → বিস্তারিত।
লেসনের গঠন: id, lessonNumber, title, titleBn, topic, activities[{no,title,canDo,dialogues[]}], dialogues[], vocabulary[], grammar[], kanji[]।
অডিও সবসময় ব্রাউজারের জাপানিজ TTS-এ চলে (কোনো MP3 ফাইল লাগে না)।
মক টেস্টের প্রশ্ন `src/data/mock_exam.json`-এ; শোনার প্রশ্নে `transcript` দিলে অডিও ছাড়াও TTS-এ চলবে।
