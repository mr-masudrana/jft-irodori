# Irodori JFT-Basic Mastery App (v2.0)

Modern mobile-first web application with a 3-step hierarchical navigation flow:
1. **Home Page:** Select Irodori Book (`Starter A1`, `Elementary 1 A2`, `Elementary 2 A2`) with live progress bars.
2. **Lesson List Page:** Browse all lessons in the selected book with completion badges.
3. **Lesson Study Page:** Interactive Dialogue player (1x & 2x JFT Exam Mode), Script toggle, Vocabulary cards, Grammar notes, and a dedicated Kanji section.

## Deploy on Cloudflare
1. Push this folder to your **Private GitHub Repository**.
2. Connect to **Cloudflare Pages** (Build command: `npm run build`, Output directory: `dist`).
