# Irodori JFT-Basic App (v4.4)

PWA: Irodori লেসন + SRS রিভিউ + শব্দ কুইজ + JFT-Basic মক টেস্ট।

## চালানো
```
npm install
npm run dev
npm run build
```

## v4.4 — Starter বইয়ের সূচিপত্র অনুযায়ী ডেটা
- লেসন ১–১৮: "Tips for life in Japan" সেকশন (ইংরেজি + বাংলা), লেসন ১ ও ২-এ Hiragana / Katakana Words লেবেল
- লেসন ৩–১৮: গ্রামার নোটের সব উদাহরণ (একাধিক হলে আলাদা লাইনে) ও কান্জি ওয়ার্ডসের রিডিং ও বাংলা অর্থ
- লেসন ১–২-এ গ্রামার/কান্জি নেই, তাই ওই সেকশন ও লেসন-তালিকায় ফাঁকা এন্ট্রি দেখানো হয় না

## v4.1 UI/UX আপডেট
- নতুন ডিজাইন সিস্টেম: আইজোমে-নীল (藍) + শু-লাল (朱), হিরোতে সেইগাইহা ঢেউয়ের নকশা, সম্পন্ন কাজে হানকো সিলমোহর (済 / 合格 / 優良可)
- হোম: দৈনিক XP লক্ষ্যের রিং, সময়ভিত্তিক শুভেচ্ছা, "যেখানে থেমেছিলেন" কার্ড, রিভিউ ট্যাবে বাকি-সংখ্যার ব্যাজ
- ফ্ল্যাশকার্ড: ডানে/বামে সোয়াইপ, পরের রিভিউয়ের দিন বাটনে দেখানো, ভাইব্রেশন ফিডব্যাক, বড় গোলাকার জাপানিজ ফন্ট (Zen Maru Gothic)
- মক টেস্ট: শুরুর স্ক্রিন (টাইমার এখন "শুরু করুন" চাপলে চলে), "পরে দেখব" পতাকা, নিচে স্থির পূর্ববর্তী/পরবর্তী বার, নিজস্ব জমা-নিশ্চিতকরণ শিট
- অ্যাক্সেসিবিলিটি: বড় টাচ টার্গেট (৪০–৪৮px), ফোকাস রিং, কীবোর্ড সাপোর্ট, reduced-motion সম্মান

## v4 পরিবর্তন

- SRS ফ্ল্যাশকার্ড (১/২/৪/৮/১৬ দিন), শব্দ কুইজ, স্ট্রিক, XP, ৭ দিনের চার্ট
- মক টেস্ট: ইতিহাস সেভ, বিভাগভিত্তিক ফলাফল, ভুল উত্তরের তুলনা, প্রশ্ন অনুযায়ী টাইমার
- নতুন UI: নিচের ট্যাব বার, ডার্ক মোড, safe-area, zoom চালু

## কনটেন্ট যোগ
ডেটার গঠন: `src/data/books/<বই>/book.json` (বইয়ের তথ্য) + `src/data/books/<বই>/lesson_01.json`, `lesson_02.json` ... নতুন ফাইল যোগ করলে নিজে থেকেই লোড হয় (index.js বদলাতে হয় না)।
URL hash দিয়ে নেভিগেশন চলে: রিফ্রেশে একই পেজে থাকে, ফোনের ব্যাক বাটন ধাপে ধাপে পেছনে যায়।
নেভিগেশন: বই → লেসন (টপিকসহ) → লেসনের অ্যাক্টিভিটি/বিস্তারিত → বিস্তারিত।
লেসনের গঠন: id, lessonNumber, title, titleBn, topic, activities[{no,title,canDo,dialogues[]}], dialogues[], vocabulary[], grammar[], kanji[]।
অডিও থাকলে `public/audio/...` এ রাখুন, না থাকলে TTS চলবে।
মক টেস্টের প্রশ্ন `src/data/mock_exam.json`-এ; শোনার প্রশ্নে `transcript` দিলে অডিও ছাড়াও TTS-এ চলবে।
